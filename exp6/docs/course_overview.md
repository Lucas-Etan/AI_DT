# 人工智能开发技术（Python）课程说明

## 课程与课时

人工智能开发技术（Python）是一门面向计算机科学与技术专业本科生的实验课，共三十二课时，安排八次实验，每次实验四课时。每次实验围绕一个完整应用主题，按环境核验、核心实现、运行验证和结果分析逐步推进。

## 运行设备与环境

课程以普通笔记本电脑为基线：不要求独立显卡，处理器使用 CPU，内存约十六 GB。实验统一使用 Python 3.12；八个实验分别创建独立的 `.venv`，禁止多个实验共用同一虚拟环境。这样可以隔离依赖版本，便于复现和排错。

## 学习方式

实验过程中请保留关键命令、版本信息、预期结果与实际结果。程序失败时，可以先阅读异常最后一行，再核对当前目录、虚拟环境、输入文件和参数；仍无法定位时，建议整理成可复现的问题记录。实验报告中请说明问题拆解、验证依据和失败分析。
