# 实验提交与评分说明

## 必交内容

实验提交包必须包含项目根目录中的 Python 源代码、`docs` 目录中的课程知识库、`outputs/evaluation_report.json`、记录实验过程的 `report.md`，以及由 `pip freeze` 生成的 `environment.txt`。报告须展示至少一个资料内问题、一个资料外问题和一组 Top-K 对比结果。

## 不得提交的内容

提交包不得包含 `.venv`、模型缓存目录、访问密钥、`.env` 文件以及可重新下载的大模型权重。任何 API 密钥都只能通过环境变量传入。若把密钥写进代码或截图，应立即作废并重新生成密钥。

## 评分关注点

建议评分结构为：可复现运行四十分，检索与问答结果三十分，误差分析二十分，目录规范与安全性十分。只展示一次成功输出、没有版本记录或没有资料外拒答测试，均不能证明系统可靠。
