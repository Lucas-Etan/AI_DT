# 在线接口与回答边界

## 在线接口配置

在线模式只从环境变量读取 `LLM_API_KEY`、`LLM_BASE_URL` 和 `LLM_MODEL`。密钥不得写入 Python 文件、Markdown 报告、终端截图或版本库。接口返回 401 时应检查密钥和服务地址；返回 429 时应降低频率并按服务方规则退避；发生超时时应缩短上下文并有限次重试，不得无限循环。

## 资料边界与引用

生成器只能依据检索上下文回答。资料内回答必须携带可追溯的来源编号，编号应能映射到文件名和片段编号；资料外问题统一返回“资料中没有足够依据，无法回答。”确定式抽取模式只是用于验证检索、引用和拒答链路的基线，它不是大语言模型，不得把拼接片段描述成模型生成结果。

## 本地模型

可选本地生成器使用 `Qwen/Qwen2.5-0.5B-Instruct`，在 CPU 上以确定性解码运行。首次使用需要下载模型权重并占用额外磁盘，生成速度明显慢于在线接口；十六 GB 内存机器应限制上下文和新生成 Token 数，关闭采样，并避免同时运行多个模型进程。
