# 实验报告提交及评分标准：实验 06

> 实验名称：文本嵌入与 RAG 知识库问答  
> 学时：4 课时  
> 满分：100 分

## 1. 基本信息

实验报告首页应填写课程、实验名称、班级、学号、姓名、完成日期、个人工作目录和生成器模式。在线 API 与本地 Qwen 均为选做路径。

## 2. 实验报告建议结构

1. 实验目的与检索—门控—生成—引用链路。
2. 环境、CPU、依赖、资料和模型状态。
3. 文本读取、切分、重叠和片段统计。
4. 嵌入形状、归一化和 Top-K 检索。
5. 阈值拒答、编号上下文和引用后处理。
6. 确定式生成器的端到端结果；选做路径单独记录。
7. Hit@K、Recall@K、拒答准确率和引用完整率。
8. 至少一个错误案例的层次归因、分析题和总结。

## 3. 提交材料

身份截图属于提交前必验项。报告至少包含两张清晰截图：一张来自环境与身份登记阶段，一张来自实验手册指定的最终验收阶段。每张截图都需要同时显示 `STUDENT_ID`、`EXPERIMENT_ID`、`IDENTITY_CODE`、`CAPTURED_AT` 和对应阶段的真实运行输出；学号应与报告首页一致。只粘贴学号文字，或把身份信息与运行结果分成互不关联的截图，不能替代这两张验收截图。

- [ ] `outputs/student_identity.json` 已生成，学号与实验编号正确。
- [ ] 环境检查和 RAG 评价两张验收截图均带学号及对应运行输出。
- [ ] FILL-01 至 FILL-15 均已完成，项目中没有未完成异常。
- [ ] chunks.json 显示 4 份资料和预期片段统计。
- [ ] embeddings.npy 的形状和 dtype 记录。
- [ ] 资料内问题与资料外问题的 JSON 输出。
- [ ] evaluation_report.json。
- [ ] 指标表、阶段运行证据和至少一个错误归因。
- [ ] 在线 API 未运行时明确写 SKIP：未配置密钥。
- [ ] 实验手册.md 第 13 节 8 道分析题答案。

建议提交包命名为：学号_姓名_实验06_RAG.zip。

不得提交 .venv、Python 缓存、模型缓存、API 密钥、下载模型和无关大文件。

## 4. 评分标准

| 项目 | 分值 | 主要判据 |
| :-- | --: | :-- |
| 环境与资料处理 | 15 | 独立环境，读取稳定，切分和重叠正确 |
| 嵌入与检索 | 25 | CPU 嵌入、归一化、索引和 Top-K 正确 |
| 上下文与引用 | 15 | 编号一致，越界引用处理，来源可追踪 |
| RAG 管线与拒答 | 20 | 前置门控，抽取基线可运行，资料外拒答 |
| 评价与归因 | 15 | 指标分母正确，报告可复核，能定位错误层次 |
| 报告与工程规范 | 10 | 学号截图和证据充分，无敏感信息泄漏 |
| 合计 | 100 | |

## 5. 扣分与诚信要求

缺少带学号的验收截图、截图学号与首页不一致或截图没有对应运行输出时，报告先退回补充，不进入评分。

本地 Qwen 与在线 API 均为选做路径，没有密钥不扣分。伪造在线结果、修改语料或预测来迎合真值、把无引用回答描述为有证据回答，相关部分不得分。

## 6. 选做扩展

可比较本地 Qwen 与确定式基线、使用获授权的在线接口、改变切分长度与重叠、分析不同 Top-K 或阈值。所有扩展必须复用同一评价集，并与必做结果分开报告。
