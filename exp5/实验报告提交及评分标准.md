# 实验报告提交及评分标准：实验 05

> 实验名称：Transformer 与大语言模型推理基础  
> 学时：4 课时  
> 满分：100 分

## 1. 基本信息

实验报告首页应填写课程、实验名称、班级、学号、姓名、完成日期、个人工作目录和本地模型 ID。在线接口状态必须明确写为 SKIP、PASS、FAIL 或真实异常。

## 2. 实验报告建议结构

1. 实验目的与 Transformer 推理流程。
2. 环境、CPU、依赖、本地模型和缓存记录。
3. token、token ID、聊天模板与生成提示后缀观察。
4. 贪心、低温和高温三种解码策略比较。
5. 上下文 token 预算、裁剪规则和边界用例。
6. JSON 提取、Pydantic 字段约束和跨字段规则。
7. 4 类故意反例与拒绝原因。
8. 在线接口状态、资源限制、分析题和总结。

## 3. 提交前验收与提交材料

身份截图属于提交前必验项。报告至少包含两张清晰截图：一张来自环境与身份登记阶段，一张来自实验手册指定的最终验收阶段。每张截图都需要同时显示 `STUDENT_ID`、`EXPERIMENT_ID`、`IDENTITY_CODE`、`CAPTURED_AT` 和对应阶段的真实运行输出；学号应与报告首页一致。只粘贴学号文字，或把身份信息与运行结果分成互不关联的截图，不能替代这两张验收截图。

检查未完成填空：

~~~powershell
Get-ChildItem -Filter *.py | Select-String -Pattern "TODO\(FILL-"
~~~

预期结果：无输出。

逐项确认：

- [ ] `outputs/student_identity.json` 已生成，学号与实验编号正确。
- [ ] 环境检查和结构化校验两张截图均带学号及对应运行输出。
- [ ] FILL-01 至 FILL-14 均已完成。
- [ ] 00_env_check.py 的版本、CPU 和内存记录。
- [ ] 00_model_check.py 的参数量、设备、缓存和加载时间。
- [ ] 01_inspect_tokens.py 的 token 与模板观察。
- [ ] 02_compare_decoding.py 的三种策略输出。
- [ ] 03_context_window.py 的裁剪前后 token 和保留状态。
- [ ] 04_structured_json.py 的原始文本与真实校验状态。
- [ ] 05_validation_cases.py 的 4 类反例拒绝证据。
- [ ] 05_online_api.py 的 SKIP、真实成功状态或真实异常。
- [ ] outputs/ 中规定的 JSON；若结构化失败，提交错误记录并解释。
- [ ] 模型 ID、包版本、缓存大小、加载时间、生成时间和内存。
- [ ] 实验手册.md 第 12 节分析题答案。

不得提交 .venv、hf_cache、模型权重副本、API 密钥和无关大文件。

| 维度 | 分值 | 判定依据 |

| 环境与模型核验 | 15 | 独立环境、CPU、参数量、缓存与资源记录真实 |

## 5. 扣分与诚信要求

缺少带学号的验收截图、截图学号与首页不一致或截图没有对应运行输出时，报告先退回补充，不进入评分。

伪造在线成功、泄露密钥、手工修改生成 JSON 冒充校验通过中的任一项，相关部分不得分。自然语言输出看似合理但未通过程序校验，不能记录为结构化任务成功。
